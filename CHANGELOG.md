# Changelog

## n8n-nodes-arkrel 0.1.4

First release from this repository as it is published today. No functional changes from 0.1.3.

- **Arkrel** node: Upload Document (invoice, receipt, bank statement, purchase order, delivery note, or a custom schema) and Get Result (JSON, CSV, XLSX, and for bank statements QuickBooks CSV, Xero CSV or OFX).
- **Arkrel Trigger** node: starts a workflow when a document reaches a result (succeeded, partial, needs review, failed) and verifies the webhook signature first.
- Built and published by GitHub Actions with npm provenance.

Also in this repository (not part of the npm package): MCP server configs and the official MCP Registry listing (`com.arkrel/arkrel`), the Cursor plugin, and the Gemini CLI extension.
